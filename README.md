# Microplastic-detection-in-water
### **Project: Microplastic Detection in Water Using IoT**

* Developed an IoT-based system to monitor and detect the presence of microplastics in water.
* Designed a prototype that integrates sensors with a microcontroller for real-time water quality monitoring.
* Collected and analyzed sensor data to identify changes in water parameters that may indicate microplastic contamination.
* Enabled real-time data transmission to a cloud platform for remote monitoring and analysis.
* Focused on providing an affordable and scalable solution for environmental water quality assessment.
* Improved awareness of water pollution by supporting early detection and continuous monitoring.
* Technologies Used: IoT, Sensors, Microcontroller (Arduino/ESP32/Raspberry Pi), Cloud Platform, Python (if applicable).
